# 🏠 Airbnb Data Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on an Airbnb listings dataset to understand listing characteristics, pricing patterns, availability, reviews, and differences between room types and locations.

The analysis focuses on **data cleaning, statistical analysis, and visualization** using Python's data analysis and visualization libraries.

---

## 🎯 Objectives

* Understand the structure and characteristics of Airbnb listings.
* Clean and prepare the dataset for analysis.
* Analyze numerical and categorical variables.
* Identify patterns in Airbnb prices and availability.
* Explore relationships between reviews, minimum nights, price, and availability.
* Compare Airbnb listings across different room types and neighbourhoods.
* Identify distributions and potential outliers in the dataset.

---

## 🛠️ Technologies Used

* **Python**
* **Jupyter Notebook**
* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical operations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization

## 📊 Dataset

The dataset contains Airbnb listing information such as:

* Host information
* Neighbourhood and location
* Latitude and longitude
* Room type
* Price
* Minimum nights
* Number of reviews
* Reviews per month
* Host listing count
* Availability
* Rating
* Bedrooms
* Beds
* Baths

## 🧹 Data Cleaning

The dataset was examined and prepared before performing the analysis.

The cleaning process included:

* Checking for missing values
* Handling missing numerical values using statistical measures
* Checking data types
* Examining potential outliers
* Preparing categorical and numerical variables for analysis

---

## 📈 Exploratory Data Analysis

The project includes:

### Univariate Analysis

Analysis of individual variables using:

* Histograms
* KDE plots
* Box plots
* Count plots
* Descriptive statistics

### Bivariate & Multivariate Analysis

Relationships between variables were explored using:

* Scatter plots
* Pair plots
* Box plots
* Categorical comparisons
* Correlation analysis
* Heatmaps

A pair plot was also used to examine relationships between:

* Price
* Minimum nights
* Number of reviews
* Availability

These relationships were further compared based on **room type**.

## 📊 Key Areas Explored

The analysis investigates questions such as:

* How are Airbnb prices distributed?
* Which room types are most common?
* How does price vary between room types?
* How are listings distributed across neighbourhoods?
* What is the relationship between price and reviews?
